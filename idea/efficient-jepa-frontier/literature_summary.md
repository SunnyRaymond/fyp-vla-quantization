| 已核实论文（版本与日期） | 机制贡献及对候选 idea 的边界 |
|---|---|
| [Fast LeWorldModel](https://arxiv.org/abs/2606.26217v1), v1, 2026-06-24 | action-prefix encoder + parallel latent predictor，一次预测各 action-prefix 对应的多 horizon latent；直接占据“action-prefix parallel rollout”。作者报告其协议下 dynamics 模块 3.9×、完整 CEM solve 约快 48%；仍用与 LeWM 相同的 terminal goal cost 和 CEM。 |
| [Latent Geometry Beyond Search: Amortizing Planning in World Models](https://arxiv.org/abs/2605.08732v2), v2, 2026-06-05 | 冻结 LeWM latent 上的 goal-conditioned inverse dynamics model 以 `(z, z_goal, remaining horizon)` 直接输出下一动作，7/8 cells 匹配或超过 CEM，论文报告 100–130× per-decision cost reduction。直接占据通用 goal→action amortization；它是 controller，不是候选轨迹的 cost surrogate，且不显式考虑多步后果。 |
| [Temporal Straightening for Latent Planning](https://arxiv.org/abs/2603.12231v3), v3, 2026-08-11 | 训练时以 curvature regularizer 拉直 JEPA latent trajectories，使 Euclidean goal distance 更贴近可行路径几何，直接支持 gradient-based action planning；“smooth latent geometry enables gradient planner”已被直接提出。论文称其 setup 中开环成功率增 20–60%、MPC 增 20–30%。 |
| [Temporal-Distance-JEPA](https://arxiv.org/abs/2607.25337v2), v2, 2026-07-29 | 从 reward-free trajectories 学 directed temporal cost（同轨迹顺序为正样本、跨轨迹负样本，并做 horizon consistency）；该 cost 可直接用作规划目标。因此泛化的 goal-progress / learned cost head 已有覆盖；它仍用 latent rollout + CEM/iCEM，没有声称省掉动力学调用。 |
| [Mind the Gap: Promises and Pitfalls of Hierarchical Planning in LeWorldModel](https://arxiv.org/abs/2607.12547v2), v2, 2026-07-15 | Hi-LeWM 冻结低层 LeWM、用高层预测 latent subgoal/macro-action。高层 CEM 会选出低预测终点 cost、但中间不可控的 subgoal；基于数据 trajectory macro bank 的 residual search 可缓解。已占据通用 temporal abstraction / macro-action proposal。 |
| [AD-WM: Action-Discriminative World Models for Counterfactual Model Predictive Control](https://arxiv.org/abs/2609.30264v1), v1, 2026-09-24 | residual dynamics + predictor-level action recovery / normalized MI objective，让模型预测保留候选 action 差异；提出 CEM elite-regret 诊断。它直接覆盖泛化的 action-aware / elite-aligned training idea，但 planner 仍为原 CEM，本身不是 latency 方案。 |
| [INTACT: Isomorphic Intent-to-Action Learning for Search-Free World Models](https://arxiv.org/abs/2607.26056v1), v1, 2026-07-28；[official repo](https://github.com/zju3dv/INTACT-JEPA) 2026-09-14 更新因果 history evaluation | end-to-end shared intent-to-action likelihood 将物理 transition 与 goal intent 共用 action operator，Direct 模式输出 action chunk；也可用少量 local CEM 验证。进一步占据零搜索 action proposal。引用结果需区分 v1 paper 与 repo 9/14 corrected-history 结果。 |
| [FF-JEPA](https://arxiv.org/abs/2606.09311v1), v1, 2026-06-08；[Qantara](https://arxiv.org/abs/2607.04978v1), v1, 2026-07-06 | FF-JEPA 用 action-free latent planner 产生 subgoal，再由 action-conditioned planner 做短期优化；Qantara 用同一 checkpoint 支持 latent planning、behavior cloning 与 inverse-dynamics 控制。两者说明层级 subgoal 与多范式/直接控制接口已有工作。 |
| [Sub-JEPA](https://arxiv.org/abs/2605.09241v1), v1, 2026-05-10；[LpWM](https://arxiv.org/abs/2608.22764v1), v1, 2026-08-24 | Sub-JEPA 将 Gaussian anti-collapse constraint 放到多个随机子空间，属于 representation regularization；LpWM 的稀疏 latent 可降低达到规划性能所需 predictor capacity。二者可启发模型容量压缩，但没有直接解决候选 rollout 的串行 planner cost。 |
| [Learning from Reward-Free Offline Data: A Case for Planning with Latent Dynamics Models (PLDM)](https://papers.nips.cc/paper_files/paper/2025/hash/3e7cf447f21cd11c846463affefce665-Abstract-Conference.html), NeurIPS 2025；[SOLD](https://proceedings.mlr.press/v267/mosbach25a.html), ICML 2025 | PLDM 是 reward-free JEPA latent dynamics + test-time planning 的基线；SOLD 是 slot object-centric dynamics / manipulation model。二者是相关能力边界，未直接提出上述规划加速机制。 |
| [V-JEPA 2](https://arxiv.org/abs/2506.09985v1), v1, 2025-06-11；[V-JEPA 2.1](https://arxiv.org/abs/2603.14482v1), v1, 2026-03-15 | V-JEPA 2 先大规模视频预训练，再以机器人轨迹 post-train action-conditioned V-JEPA 2-AC 做 image-goal planning。2.1 的更新重点是 dense / temporally consistent video features 与训练目标，不是新的 planner acceleration；本次定向检索未发现正式 V-JEPA 2.2 paper。 |

## Collision 判定与边界

- **已有直接占据：** action-prefix parallel multihorizon prediction（Fast-LeWM）；goal-conditioned direct action proposal（GC-IDM、INTACT，另有 Qantara）；smooth latent gradient planning（Temporal Straightening）；learned temporal goal cost（Temporal-Distance-JEPA）；macro-action / subgoal proposal（Hi-LeWM、FF-JEPA）。泛化版本不宜作为 novelty claim。
- **仍未核实的窄问题：** 是否已有一个只蒸馏 CEM 候选的终端 cost / ranking surrogate，从而省去 latent predictor calls，同时保留 elite-set、first-action 与闭环 fidelity；或一个按误差/不确定性选择 rollout intervals 的 planner，能绕开 Fast-LeWM 已覆盖的固定多 horizon parallel prefix 输出。本次 Phase 0 失败，不能把“没找到”写成“无人做过”；需要恢复结构化检索、检查对应完整论文与实现后才可定 novelty。
- 论文报告的 latency / success 数字都只代表其各自 protocol；这里没有重测，不外推到本地 LeWM + PushT 配置，也不构成闭环比较。
