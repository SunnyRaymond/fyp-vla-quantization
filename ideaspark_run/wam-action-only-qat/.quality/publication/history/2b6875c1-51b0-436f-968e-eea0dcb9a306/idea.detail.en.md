# Student-Path Suffix QAT for World-Action Models

**Method.** Student-Path Suffix QAT (SPS-QAT)

## Motivation
**Problem framing.** The bottleneck is attribution: a low-bit WAM result cannot establish the value of action-path training unless parameter scope, bitwidth, denoising schedule, excluded precision, and inference accounting are matched. This matters because SteerQuant reports near-BF16 LIBERO success at W4A8 with packed weights fixed, QuantWAMs reports strong weight-frozen PTQ, and Q-WAM obtains near-BF16 control with a protected 16-bit subspace under W4A4. These results make a failure premise untenable; they leave the conditional benefit of training-time adaptation over strong PTQ and matched distillation unidentified.

The initial Fast-WAM Base instance permits an independently parameterized ActionDiT to be targeted while its approximately 5B video expert and visual cache remain BF16; the stated roughly 1B action expert yields only about 1.14x idealized total core-weight reduction when the larger video expert stays BF16. LingBot-VA and Cosmos Policy instead use shared-backbone action/video computation, so adapting their shared denoiser blocks is action-targeted shared-backbone QAT, not weight-scope action-only QAT. The proposal therefore tests one suffix-response training operator under distinct model contracts and keeps fixed-input command fidelity, closed-loop completion, and native full-query latency as separate evidence.

**Why now.** Recent WAM PTQ work provides strong, concrete matched-scope baselines, while recent diffusion QAT work such as QVGen and EfficientDM shows that low-bit adaptation is technically studied in neighboring generative settings but does not establish robot-action or control fidelity. Public Fast-WAM LIBERO demonstrations, checkpoint and normalization statistics, together with released model interfaces for LingBot-VA and Cosmos Policy, make a bounded first pilot and separately scoped transfer checks formulable now; the available evidence does not establish memory fit, throughput, or a positive result.

**Why prior work stopped.**
- `arxiv:2609.39056v1` (arXiv 2026): SteerQuant maps layer, solver-step, and stream quantization errors to downstream action sensitivity, then calibrates shared weight and stream/timestep activation scales while keeping packed weights fixed.
  - _Did not do_: It does not compare training-time action-weight adaptation against matched branch-free W4A8 PTQ and teacher distillation at the same module scope and deployed arithmetic.
  - _Structural reason_: Its reported mechanism is PTQ calibration with fixed packed weights, so an equal-scope trainable-weight comparison is outside the measured procedure.
- `arxiv:2607.28405v1` (arXiv 2026): QuantWAMs aligns PTQ grouping, objective, calibration distribution, and fixed-intervention rollout auditing with WAM structure while retaining pretrained weights.
  - _Did not do_: It does not identify whether action-path adaptation improves outcomes over an equal-scope, matched-cost training comparison.
  - _Structural reason_: The method calibrates a frozen pretrained model, so its procedure does not update weights to test the incremental QAT effect.
- `arxiv:2609.33269v1` (arXiv 2026): Q-WAM protects an action-sensitive subspace in a 16-bit low-rank branch while quantizing the complement to W4A4.
  - _Did not do_: It does not measure a branch-free W4A8 action-targeted QAT contract against matched PTQ and distillation.
  - _Structural reason_: Its precision allocation and protected branch define a different mechanism and deployment scope from matched branch-free W4A8 weight adaptation.
- `arxiv:2505.11497v5` (arXiv 2025): QVGen uses trainable error-compensation auxiliaries and rank decay to stabilize low-bit video-diffusion generation.
  - _Did not do_: Its reported evidence does not establish denormalized robot-action fidelity or closed-loop WAM control.
  - _Structural reason_: The evaluated objective and outcomes concern video generation and do not include a WAM controller-facing action map or control measurement.
- `arxiv:2310.03270v4` (arXiv 2023): EfficientDM combines quantization-aware low-rank updates with teacher denoising-output matching for low-bit image diffusion.
  - _Did not do_: It does not construct a WAM-native suffix endpoint in denormalized executed-action coordinates or establish closed-loop action fidelity.
  - _Structural reason_: Its image-diffusion task does not provide the robot action normalization, executed-prefix, and controller outcomes needed to identify this WAM-specific question.

**What changes when the gap closes.** A positive, matched result would identify when updating a fixed W4A8 action-targeted parameter scope adds closed-loop value over strong frozen-weight PTQ and teacher-state distillation, rather than attributing the result to a changed precision or inference contract. Separate Fast-WAM and shared-backbone results would show where that conclusion transfers; fixed-input fidelity or lower action-block time alone would not establish the same capability.

## Method
**Pipeline.** First record each model's BF16 reference, exact matched branch-free W4A8 module scope, native solver, action maps, prefix selector, and deployment contract. Generate the fake-quant student path from the model's existing LIBERO training episodes and native noise, then sample a native active solver state and restart both the BF16 teacher and student through the same remaining suffix. Train only the student's declared quantized weights with a dimensionless, per-channel-scaled continuous pre-threshold endpoint residual, while separately reporting exact executed-command differences. Compare against matched PTQ and distillation controls, then report fixed-input deviation, closed-loop completion, and full native action-query latency separately before attempting scope-labeled shared-backbone transfer.

### M1_background
*Record each model's contract and generate the fake-quant student's own solver path.*

1. **Record each model contract** (`S1`)
   - For Fast-WAM Base, released shared-backbone LingBot-VA, and Cosmos Policy's LIBERO model, record the BF16 reference, native schedule, action normalization/denormalization maps $D_{m}$, executed-prefix selector $E_{m}$, exact matched branch-free W4A8 module set $Q_{m}$, and precision/kernel contract; designate only existing trainable weights $theta_{m}$ in $Q_{m}$. Fast-WAM's independent ActionDiT is a weight-scope action-only target, whereas shared denoiser blocks in the other two models must be labeled action-targeted shared-backbone scope.
   - _Why:_ A comparison cannot identify the incremental value of adaptation if module scope, non-target precision, schedule, or deployed arithmetic changes across arms.
2. **Generate the quantized student path** (`S2`)
   - Split each named LIBERO dataset by episode, sample training contexts c only from its training episodes, draw initial noise z and solver innovations eta from that model's native inference distribution, and run the fake-quant student through its native schedule to record the required evolving states $x_{Q}[m,k]$ for active indices $K_{m}$. The state contains action latents for Fast-WAM and coupled video/action state for shared models.
   - _Why:_ The target is conditioned on states the quantized model itself reaches, while the fixed context/noise protocol preserves paired comparisons and does not claim to model environment observations after executed actions.

### M2_suffix_target
*Train from a student-visited state using paired full-suffix endpoints.*

3. **Pair the remaining suffixes** (`S3`)
   - Sample k uniformly from $K_{m}$, detach $x_{Q}[m,k]$, and restart both the BF16 teacher and fake-quant student from that identical state with the same c and remaining native innovations eta_after_k; apply each unchanged full remaining suffix S[b,m,k] and retain both endpoint action chunks.

*The visit-response difference is measured after the native action map and exact executed-prefix selector, using the same remaining innovations from a state reached by a fixed matched W4A8 PTQ reference student.*
$$ \delta^{\mathrm{PTQ-ref}}_{m,k,u,j}=\left[E_m\!\left(D_m\!\left(S[Q_{\mathrm{ref}}|Q_{\mathrm{ref}},m,k](x_{Q_{\mathrm{ref}},m,k},c,\eta_{>k})\right)\right)-E_m\!\left(D_m\!\left(S[\mathrm{BF16}|Q_{\mathrm{ref}},m,k](x_{Q_{\mathrm{ref}},m,k},c,\eta_{>k})\right)\right)\right]_{u,j} \tag{1} $$

   - _Why:_ This is the candidate's load-bearing operator: compare suffix response from a state reached by the student, rather than only comparing teacher and student at their original noise-seed endpoints or at teacher-visited states.
4. **Train on the scaled action endpoint** (`S4`)
   - Apply $D_{m}$ and $E_{m}$ to each endpoint up to any hard clip or gripper threshold to obtain continuous pre-threshold commands; when gripper thresholding exists, use its continuous pre-threshold signal for gradients. Scale every selected channel j in $J_{m}$ by its existing positive model/controller scale s[m,j], fixed across arms, average the squared residual across all $T_{exec},m$ native prefix steps and $J_{m}$ channels, and backpropagate only through the student suffix into $theta_{m}$. Separately report exact clipped/thresholded executed-command deviation per channel in native units; keep quantizer scales, schedule, excluded precision, and action interface fixed. The training residual or any required STE is a gradient-bearing surrogate related to, but not identical to, the exact physical-command metric.

*The student suffix is trained on the dimensionless mean squared continuous pre-threshold command residual across every native executed-prefix time step and selected action channel; only the student suffix receives gradient.*
$$ \mathcal{L}_{\mathrm{train},m}=\mathbb{E}_{c,z,\eta,k}\!\left[\frac{1}{T_{\mathrm{exec},m}|J_m|}\sum_{u=1}^{T_{\mathrm{exec},m}}\sum_{j\in J_m}\left(\frac{\tilde y_{Q|Q,m,k,u,j}-\tilde y_{\mathrm{BF16}|Q,m,k,u,j}}{s_{m,j}}\right)^2\right] \tag{2} $$

   - _Why:_ Native denormalization and prefix selection place the target in controller-facing coordinates; temporal and per-channel averaging makes the training signal a scalar without pretending the differentiable surrogate equals the executed command.

### M3_validation
*Compare matched training controls, separate outcomes, and test scoped transfer.*

5. **Match training controls and accounting** (`S5`)
   - Compare the candidate with ordinary action-only QAT plus teacher KD, matched branch-free W4A8 PTQ, original-noise-seed endpoint KD, teacher-state suffix KD restarted from $x_{FP}[m,k]$, and student-state per-step OPD at $x_{Q}[m,k]$. Count vanilla action-only QAT plus teacher KD and teacher KD at teacher states as one arm whenever targets and objectives are identical. Match total measured training GPU-time or, when matching solver work, total teacher and student NFE; keep model-specific episode splits, scope, contexts, and paired noise/solver-index draws aligned, and report teacher/student NFEs, GPU-time, examples, unique-context and repeated exposure, optimizer updates, and teacher-suffix work. For a shared-backbone per-step OPD comparison, mask loss to controller-selected action channels and native prefix steps with no video-output loss, and label it action-targeted shared-backbone training; any video-plus-action objective is a separately named scope and cost.
   - _Why:_ The matched controls isolate whether the paired full-suffix endpoint target adds value beyond QAT, ordinary endpoint KD, teacher-state suffix KD, and student-state per-step supervision while making teacher-paid work visible.
6. **Separate fidelity, control, and latency outcomes** (`S6`)
   - On held-out fixed contexts and paired noise, measure exact denormalized executed-action deviation separately from LIBERO closed-loop completion; then measure full native W4A8 action-query latency without a teacher, including video/context prefill. Compute the visit-energy diagnostic over the entire native prefix time-by-channel tensor as a scalar using the same fixed pre-QAT matched-PTQ reference checkpoint in every arm; this Phase4 supplement clarifies estimator definition and provenance only, and is not a passed post_revision gate. Report measured action-time share and use Amdahl's law for any whole-query speed inference; do not turn an action-layer 4x storage reduction into a whole-WAM 4x compression or speed claim.

*Phase4 supplement: reduce the exact executed-command response over the full native time-by-channel prefix to one scalar, estimated only from a fixed pre-QAT matched-PTQ checkpoint for every arm; this definition is not a passed post_revision gate.*
$$ \mathcal{V}^{\mathrm{PTQ-ref}}_{\mathrm{visit},m}=\mathbb{E}_{c\sim\mathcal{D}^{\mathrm{eval}}_m,z,\eta,k\sim\operatorname{Unif}(K_m)}\!\left[\frac{1}{T_{\mathrm{exec},m}|J_m|}\sum_{u=1}^{T_{\mathrm{exec},m}}\sum_{j\in J_m}\left(\frac{\delta^{\mathrm{PTQ-ref}}_{m,k,u,j}}{s_{m,j}}\right)^2\right] \tag{3} $$

   - _Why:_ Fixed-input action fidelity, closed-loop success, and deployed latency answer different questions; the association between the visit-energy scalar and completion benefit remains an empirical prediction.
7. **Test transfer under shared-backbone contracts** (`S7`)
   - Attempt separate transfer checks on released shared-backbone LingBot-VA and Cosmos Policy only under their native scope contracts; record that updating shared denoiser blocks changes video and action computation, retain the action-only output mask for action-targeted controls, and do not pool their results with Fast-WAM or call shared weights weight-scope action-only.
   - _Why:_ The user-specified extension tests whether the operator applies beyond Fast-WAM while respecting that the target models do not expose the same independent action-weight subset.

## Reviewer concerns
- **Concern [non_blocking]:** Paper-pointed threat: arxiv:2609.26708v1 (collision_hits). Train Where the Quantized Model Goes establishes that low-bit students can need frozen-teacher supervision on their own quantized prefixes, so student-visited supervision itself is not novel. It does not use a WAM solver's full remaining suffix endpoint in executed-action coordinates; the candidate's narrow paired suffix-response operator remains an open hypothesis. DiffusionOPD (arxiv:2605.15055v2) uses per-step same-state transition KL (direct L2 in its deterministic regime); AnyFlow (arxiv:2605.13724v1) uses flow-map backward simulation with DMD; DiffusionOPSD (arxiv:2608.24646v1) fits reward-derived clean-output anchors at behavior-policy query states. Their operators and targets are adjacent, not identical. The suffix rebase is an on-policy state choice, fake quantization is standard QAT, and controller-prefix masking and physical-unit scaling are task adaptation; only the full-suffix endpoint operator is a plausible structural delta. If $D_{m}$ or $E_{m}$ contains hard gripper thresholding/clipping, train with a per-channel-scaled continuous pre-threshold command residual (and a continuous gripper signal) for gradients, while separately reporting the exact executed-command metric; that surrogate, including STE, is not the identical physical-command objective. DiffusionOPSD is already in Phase 0. Collision retrieval returned arXiv, OpenAlex and OpenReview results, but no Semantic Scholar files after its bounded window, so this is not exhaustive novelty coverage.
  - **Response:** The core_mechanism and S3–S4 define only the paired full-remaining-suffix endpoint from an exact student-visited state as a plausible structural delta: Train Where the Quantized Model Goes already covers low-bit on-policy teacher guidance, DiffusionOPD uses student-state per-step transition supervision, AnyFlow uses on-policy flow-map backward simulation/DMD, and DiffusionOPSD anchors reward-derived clean outputs at behavior-policy query states; generic QAT, suffix rebasing, controller masking, and channel scaling are not presented as novelty. The Phase 3.2 verdict_rationale's scalar example shows suffix loss can decrease while original-endpoint error increases, so the falsification_prediction retains matched original-endpoint KD, teacher-state suffix KD, and student-state per-step OPD controls, and neither novelty nor a control gain is established. The Phase4 supplement defines $V_{visit}$ as a full-prefix time-by-channel scalar from one fixed pre-QAT matched-PTQ reference across arms, but this authoring clarification does not pass the recorded post_revision F1 gate or change the needs_work / FAILED VALIDATION lineage.
  - *Fields changed to address:* `core_mechanism`, `core_mechanism_steps`
