# Post-grounding collision leads

Root supplementary search, 2026-10-03. Train Where the Quantized Model Goes, DiffusionOPD, and AnyFlow were found after Phase 0 and are outside its 100-record coverage. DiffusionOPSD (`arxiv:2608.24646v1`) is already present in the Phase 0 corpus; this note adds it as a focused collision lead, not as new retrieval coverage. These are comparison leads, not an independent audit verdict. No local experiments were run.

- [Train Where the Quantized Model Goes: On-Policy Distillation for Low-Bit Reasoning](https://arxiv.org/html/2609.26708v1), Sections 3.2 and 4.1–4.2: quantization changes the student's visited prefixes; a frozen BF16 teacher supervises those prefixes after a QAD initialization. Equations (2)–(3) combine on-policy teacher guidance and verifier rewards. Merely transferring quantization-amplified exposure bias and student-state supervision to WAMs is not an established novelty claim.
- [DiffusionOPD](https://arxiv.org/html/2605.15055v2): distillation along the student's own continuous-state diffusion rollouts, with a per-step objective. Compare both the visited-state distribution and the supervision operator.
- [AnyFlow](https://arxiv.org/html/2605.13724v1), also [official project page](https://nvlabs.github.io/AnyFlow/): on-policy flow-map learning, backward simulation, and truncated gradients to control rollout cost. Compare suffix/endpoint supervision and truncation, rather than only the intended application or method name.
- [DiffusionOPSD](https://arxiv.org/abs/2608.24646): behavior-policy query states and clean-output anchors, with reward-derived targets and refreshed supervision. Abstract verified; deeper method comparison remains the critic's task.

The tentative WAM candidate must distinguish its actual objective, gradient, target, or necessary implementation constraint from these families. Controller-prefix masking, physical-unit scaling, teacher suffix rebasing, and fake quantization should each be examined for whether they change the method or are ordinary task adaptation. A teacher suffix restarted from the student's state is not the original BF16 endpoint from the initial noise, nor a physical ground-truth oracle.
