## 可确认的直接重叠与边界

四者已覆盖的核心机制分别是：Q-WAM 的 action-subspace protection；SteerQuant 的 action-guided、step/stream-aware error routing；QuantWAMs 的兼容坐标校准、joint video–action saliency 与 fixed-intervention schedule replay；PreDE 的策略专属离线行为筛选。仅以“action-aware quantization”“denoising-step sensitivity”“rollout-aware calibration”或“offline action deviation”描述新意，都会与已有机制明显重叠。

针对执行 prefix 与 affine conditioning/AdaLN，现有全文没有给出一致、直接的专项对照：QuantWAMs 保留了 chunk position 等 rollout snapshot 状态；Q-WAM 提到运行时 normalization parameters；SteerQuant 明确把 normalization 保留 BF16。其余覆盖细节未报告或无法确认，应作为证据边界记录，不能直接写成已证实 gap。
