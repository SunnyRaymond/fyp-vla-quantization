## 1. Goal-Anchored Trajectory VQ：用规划候选之间的关系校准权重 codebook

**直觉。** 把一组权重编码成 codebook index 时，仅重建每层输出，可能保不住不同动作产生的预测结果之间的关系。这个 idea 检验：在相同存储预算下，离线微调共享 codebook，能否让量化 world model 保留这种关系，并改善实际规划。

首个载体是已有 DINO-WM Wall。保留绝对 feature anchor 与真实 planner score，再加入不同候选预测之间的关系项。首轮保持 index、grouping 与压缩配置固定，仅拟合 codebook entries，避免组合式 index 搜索。它是 **weight VQ**，不是动作 tokenizer，也不依赖定制 accelerator。

**最重要的失败检验。** CEM 并不直接使用 off-diagonal 关系，因此关系误差下降本身没有意义。必须优于同一 VQ 布局的绝对重建/score-only 拟合，并在新 initial states/action probes 上改善 planner first action 与闭环结果。若只改善中间几何指标，就停止。与同目标 scalar quantization 的比较，另检验是否真的需要 VQ 的共享 codebook。

**风险。** VPTQ/AQLM、RSAVQ、MotionVQ 已覆盖大量权重 VQ 机制；relational distillation 也是直接近邻。候选差异仅限于 action-conditioned world-model 的特定拟合对象及其可验证增量，不能把新应用名称当成新原理。

## 2. Frozen-Residual Transport PTQ：校准量化误差如何在下一步传播

**直觉。** 相同的一步误差，经过下一步 world model 后可能被放大，也可能被减弱。先固定一批由初始 W4 模型实际产生的 latent residual，再让低比特模型与 FP32 模型对这些残差产生相近的响应。

核心对象是两次预测之差：

\[
T_Q(x,\delta,a)=F_Q(x+\delta,a)-F_Q(x,a).
\]

在干净输出重建之外，匹配 \(T_Q\) 与 \(T_F\)。\(\delta\) 来自冻结的初始量化器，不能在优化中自行缩成零；它只写入真实 history 的新预测槽。首轮固定 W4 配置，只离线拟合 scales/rounding，部署时丢弃训练用 rounding 参数，无需 FP teacher 或额外 observer。

**最重要的失败检验。** 必须胜过普通两步 rollout 重建、noisy-input reconstruction，以及同范数随机扰动的响应匹配。拟合后还要检查模型自身的新 residual；若仅对旧 residual bank 有效，或者随机方向同样好，就停止。

**风险。** Sobolev Training、GAD、QDrop、PD-Quant 已覆盖导数蒸馏、扰动响应和噪声校准的一般原则。这里真正待检验的是“实际量化残差的方向”是否提供额外信息，不是第一次匹配 Jacobian。

## 优先顺序与资源

建议先验证 **Frozen-Residual Transport PTQ**：改动对象较少，可以沿用 scalar quantizer 和现有 world-model 接口。VQ 候选更具探索性，codebook 与 planner 关系项的贡献都需要分别证明。

| | VQ 候选 | 非 VQ 候选 |
|---|---|---|
| 第一载体 | DINO-WM Wall | DINO-WM Wall |
| 首轮训练范围 | 固定 indices 的 codebook calibration | 固定 W4 的 quantizer calibration |
| 基础模型从头训练 | 不需要 | 不需要 |
| GPU 并发 | 1–4×A100，总并发不超过4 | 1–4×A100，总并发不超过4 |
| 首轮建议 cap | ≤16 allocated GPU-hours | ≤12 allocated GPU-hours |
| 40GB / 80GB | 40GB 小 batch 为起点；80GB 是另行配置 | 40GB 小 batch 为起点 |

这些是资源规划和停止上限，**未测量、不是完成时长保证**；总 GPU-hour 额度并非用户已给定。先用单卡最小 forward/backward 测 memory 和 step time，再冻结能够在 cap 内跑完的共同 workload。若最小对照集合无法在 cap 内完成，应报告预算不可行并停止，不只保留对本方法有利的 arms；不自动增加 GPU 数或预算。第一轮仅证明局部量化机制，不承诺整模型压缩比例或完整论文规模结果。

## 两条方案共用的实验约束

- CAL 拟合、DEV 筛选、TEST 最终确认；按 episode/initial-state 分离，Wall 首轮不宣称跨任务泛化。旧 RankCal TEST 只作为历史背景，不能成为新方法的独立确认集。
- 固定 checkpoint、source、FP32 reference、action normalization、CEM 参数、goal scoring 与随机源。配对任务使用 common random numbers；改变 quantizer fit seed 时，按重复拟合报告。
- 配置、校准数据量和计算预算与比较方法相同；frames、action pairs 和 repeated seeds 不冒充独立 episodes。小样本 pilot 用于机制筛选，不作有充分统计功效的宣称。
- codebook/index 或整数权重的真实序列化 bytes 要包含 scales、metadata、padding 和未量化参数。跨格式使用共同 byte ceiling 并报告 slack，不能只比较名义 bits。
- fake quant、packed storage、native low-bit execution 是不同证据层级。只有实际运行 kernel 并测量后，才能报告显存与速度收益。
- 本轮仅产出方案；没有启动模型、实验或集群作业。未来所有重 I/O/计算必须在核验过的真实 PBS allocation 中执行，login node 仅轻量控制；保留 host-key verification，不记录 credentials，同一文件单写者。
