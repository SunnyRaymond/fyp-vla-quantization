Develop one reviewer-defensible research idea for robot manipulation World Action Models: models that jointly or coupledly predict future observations/video and generate actions, with numerical low-bit weight and activation quantization for efficient closed-loop deployment. Distinguish this from ordinary VLA-only quantization, vector-quantization/tokenizer work, and the main branch latent rollout/planning route. QuantWM is An Empirical Study of World Model Quantization (https://arxiv.org/abs/2602.02110v1) and QuantWAMs is QuantWAMs: Calibrating at the Right Granularity for World Action Models (https://arxiv.org/abs/2607.28405v1); both are mandatory direct prior-art anchors and must be verified through pipeline connectors. Host supplemental review has already confirmed that QuantWAMs Eq.12-16 contains the joint video/action empirical-Fisher cross term and Eq.22 contains fixed-count closed-loop schedule repair, so renaming those is not novelty; it also notes QuantWM and Where Bits Matter already cover rollout/planning mismatch and module-aware allocation. Default feasibility is a small validation on NSCC ASPIRE2A A100 40GB; do not run GPU or SSH jobs and do not train a large model from scratch. Focus on a falsifiable mechanism-level gap in coupled future prediction and action generation under weight/activation quantization, with public WAM baselines and robot manipulation data. Numerical quantization means model weight/activation precision, not latent or action tokenization.
