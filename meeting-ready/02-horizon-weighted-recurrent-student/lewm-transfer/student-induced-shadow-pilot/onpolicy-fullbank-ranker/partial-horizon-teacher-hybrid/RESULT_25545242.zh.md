## Timing 与解释边界

Latency 使用 resident-on-CUDA inputs，CUDA 同步计时原生 predictor 与 official criterion 对 300 个 candidates 的完整调用，包括 teacher/student 切换；排除 bank/model I/O 与 environment 工作。每个 arm 有 3 次 warmup、5 次重复，并按冻结顺序轮换。k0 student 约 1.97 ms，k5 teacher 约 20.0 ms；k1/k2 约 5.7/9.3 ms，因此混合臂的 latency reduction 是相对 full-teacher k5，而不是相对 student-only k0 的加速结论。

结果只来自已用过的 93 个 train banks；同一批 banks 用于本 pilot 的分臂指标与冻结门槛计算，不能当作独立泛化验证。虽然 k1/k2 的 predictor-level regret 与原生计时均通过冻结门槛，这仍只是对 inference-time hybrid 的探索信号。下一步先另行冻结 fresh-episode、independent-bank gate；在该独立 gate 通过并冻结后续方案前，不接入 CEM 或评估 closed-loop treatment。
