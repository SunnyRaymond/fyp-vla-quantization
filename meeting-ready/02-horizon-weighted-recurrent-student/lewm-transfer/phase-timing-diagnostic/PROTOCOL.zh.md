# LeWM PushT: early-vs-late teacher timing diagnostic

## Question

The valid four-arm run 25535873.pbs101 found 26/50 successes for late teacher rounds 24–30, 11/50 for student-only, and 49/50 for teacher-only. This diagnostic asks where a seven-round teacher budget helps most:

- **Early distribution anchoring:** teacher scoring in rounds 1–7 prevents student cost updates from moving the CEM distribution toward weak action regions.
- **Late candidate re-scoring:** teacher scoring in rounds 24–30 corrects candidate rankings near the final distribution updates.

The experiment compares the timing of the same seven teacher rounds. A phase effect supports which placement is more useful for this frozen task set; the scalar mean/variance traces are descriptive evidence, not proof of an internal causal mechanism.

## Frozen arms and tasks

Use the exact 50 `(row_index, episode_idx, start_step)` entries from teacher baseline 25534994.pbs101 for every arm, preserving row order. Do not sample new HDF5 rows or change tasks based on the 25535873 outcomes. The four arms are student-only, early teacher rounds 1–7, late teacher rounds 24–30, and teacher-only. Early7 and late7 use seven teacher calls per CEM `start_batch`; actual aggregate call counts can differ if arms have different numbers of active batches.

Each arm uses a fresh pinned `World`, the baseline full-dataset scalers, image transforms, dataset callables and world evaluation settings. Keep goal offset 25, `eval_budget=50`, `world.max_episode_steps=100`, CEM seed 42, 30 rounds, 300 candidates, top30, and native solver RNG progression. This follows the upstream dataset evaluation protocol; it is not a verbatim `eval.py` run or a random-reset benchmark.

Before loading the dataset or model weights, save the frozen order generated by `random.Random(20260924)` from the arm list. The order is `early_teacher7`, `teacher_only`, `late_teacher7`, `student_only`.

## Route boundary and diagnostics

The pinned `CEMSolver` calls callback `start_batch()` once for each environment chunk, then executes 30 CEM iterations. Reset the route round index at each `start_batch()` while preserving the solve-wide teacher call records. Validate each batch's 30 route flags, not a flattened whole-solve sequence.

At post-update rounds 1, 7, 8, 23, 24, and 30, record only CEM mean RMS and mean variance per batch. These scalar trajectories add no model calls and do not retain candidate tensors. They are secondary, descriptive signals of when the action distribution changes.

## Analysis and decision rules

The primary contrast is paired early7 versus late7 success over the 50 unique source episodes, using the exact two-sided cluster sign-flip test. Call early timing favored only if early7 gains at least five successes and `p < 0.05`; call late timing favored only if late7 gains at least five and `p < 0.05`. Otherwise the mechanism result is inconclusive. The paired comparisons to student-only and teacher-only remain contextual/secondary.

Separately report whether the phase-favored schedule is useful relative to student-only (+5 successes and paired `p < 0.05`), its gap to teacher-only (target at most five successes), and its synchronized planner-time ratio to teacher-only (carried-forward target at most 0.70). A timing effect alone does not meet the project's quality or latency target.
