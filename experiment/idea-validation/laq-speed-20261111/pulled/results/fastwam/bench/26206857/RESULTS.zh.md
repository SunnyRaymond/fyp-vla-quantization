# LAQ 整数运行时（Fast-WAM，1 张 A100，单进程）

作业 26206857.pbs101，NVIDIA A100-SXM4-40GB，torch 2.7.1+cu128。case 2000 的观测，7 次查询（5 次后 reset 一次，再 2 次；每次换采样种子），LAQ 用与闭环相同的在线 gaze。中位数不计第 1 次（录图模式的第 1 次包含录图）。

## 显存

- BF16 算术、dense 权重的一次调用：峰值 13.03 GiB，常驻 12.78 GiB
- 目标 Linear 的 BF16 权重 11.02 GiB → 4-bit 码加每行 scale 与 bias 2.77 GiB；INT8 scratch 0.041 GiB
- 整数运行时常驻 4.62 GiB（解包成 8 bit 常驻时 11.17 GiB）
- 一次查询的 K/V 缓存（按 token 数计算，30 层，文本 129 token）：BF16 194.1 MiB，4-bit 码 53.4 MiB（不精修 50.4 MiB）。运行时里缓存以反量化后的 BF16 张量保存，这两个数是存储格式的大小。
