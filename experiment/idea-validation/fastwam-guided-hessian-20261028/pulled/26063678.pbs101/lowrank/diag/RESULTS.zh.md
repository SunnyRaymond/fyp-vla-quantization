# C2 v2 低秩支路：C80 上的 future 修复为什么到不了 held-out

作业 `26063678.pbs101`。C80 和 held-out 是同样的 40 个任务（每个任务 2 个 / 1 个不相交的 demo 快照，相位位置相同），J 在每批更新前对这批新 context 的 loss 只有 E 的 0.93–1.07 倍，训过的批次却降到 0.64–0.77 倍：修复留在训过的 context 上。这里问它跟着 context 走还是跟着那一条 sampler seed 轨迹走，以及一批的梯度有多少是别的样本共有的。
