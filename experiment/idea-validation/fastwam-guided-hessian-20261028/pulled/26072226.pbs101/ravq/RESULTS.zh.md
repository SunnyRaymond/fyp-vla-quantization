# RAVQ 未校准版：QTIP 舍入 + C1 模块级比特预算

作业 `26072226.pbs101`。舍入全部是 QTIP（A16 基线的同一份移植、同一份 H_U、同样的逐层种子），不训练任何参数。各臂只在"每类层用几 bit"上不同：接口层（action_encoder、动作 head、proprio_encoder、视频 head）存 BF16，时间条件层按 timestep 存输出表（输出与 BF16 完全一致），RAVQ 臂把动作专家主体省下的比特给视频专家主体。

## 判读

- 公平口径（QTIP W2 + 接口 BF16 + 时间表）相对原基线：mixed 0.840×，motor 0.762×，gripper 0.390×，future 0.936×。
- 公平口径（QTIP W3 + 接口 BF16 + 时间表）相对原基线：mixed 0.863×，motor 0.787×，gripper 0.663×，future 0.909×。
- 动作主体降位（同上，动作主体 1 bit）：换 BF16 future 后 motor 1.244×，motor 1.083×，gripper 1.184×，future 1.000000×。
- 动作主体降位（同上，动作主体 2 bit）：换 BF16 future 后 motor 1.116×，motor 1.030×，gripper 1.028×，future 1.000000×。
- RAVQ 未校准，2-bit 预算 对 QTIP W2 + 接口 BF16 + 时间表（比特 1.0000×）：future 0.732×，mixed 0.717×，motor 0.835×，gripper 1.183× → 上闭环（预先登记：future ≤ 0.9× 且 mixed ≤ 1.0×）。
- RAVQ 未校准，3-bit 预算 对 QTIP W3 + 接口 BF16 + 时间表（比特 1.0000×）：future 0.743×，mixed 0.733×，motor 0.908×，gripper 1.348× → 上闭环（预先登记：future ≤ 0.9× 且 mixed ≤ 1.0×）。
- 下一步闭环：QTIP W2 + 接口 BF16 + 时间表, RAVQ 未校准，2-bit 预算, QTIP W3 + 接口 BF16 + 时间表, RAVQ 未校准，3-bit 预算。
- K = 4 的视频层（48 层）：选层时估的 H_U 代理均值 0.00098，实测 0.00118。
- 检查：只改动作主体时 future NMSE 的最大相对差 0.00e+00；比特预算 满足。
